# Vault 운영 규칙

## KV 경로 규칙

**형식**: `secret/[서비스]/[항목]`


## KV 키 목록

| 경로 | 필드 | 내용 | 폴더 | 상태 |
|------|------|------|------|------|
| `secret/proxmox/ciuser` | `password` | VM ciuser 패스워드 | 00.proxmox | 적용 |
| `secret/packer/proxmox` | `api_url`, `token_id`, `token_secret` | Proxmox API 토큰 | 01.packer | 적용 |
| `secret/packer/ssh` | `password` | Packer 빌드용 SSH 패스워드 | 01.packer | 적용 |
| `secret/terraform/proxmox` | `token_id`, `token_secret` | Proxmox API 토큰 | 02.terraform | 미적용 |
| `secret/terraform/vm` | `password` | VM 기본 패스워드 | 02.terraform | 미적용 |
| `secret/minio/root` | `access_key`, `secret_key` | MinIO root 자격증명 | 03.ansible | 미적용 |
| `secret/wazuh/admin` | `password` | Wazuh admin 패스워드 | 03.ansible | 미적용 |
| `secret/k8s/registry` | `username`, `password` | Harbor 이미지 풀 시크릿 | 04.k8s | 미적용 |

```bash
# [vault-01] 저장
export VAULT_ADDR="http://127.0.0.1:8200"
vault kv put secret/[서비스]/[항목] key="value"

# [vault-01] 전체 조회
vault kv get secret/[서비스]/[항목]

# [vault-01]특정 필드 (스크립트 사용)
vault kv get -field=key secret/[서비스]/[항목]
```


## 정책 규칙

**형식**: `[서비스]-policy`

- 서비스별 정책 분리: 하나의 정책에 모든 경로 몰아넣지 않음
- 최소 권한 원칙: `read`만 필요하면 `create`/`update` 부여 금지

**예시**
```hcl
# proxmox-policy
path "secret/data/proxmox/*" {
  capabilities = ["read"]
}
```


## 토큰 규칙

- Root Token은 초기 설정 후 사용 금지 (서비스별 정책 토큰 사용)
- 토큰 TTL은 용도에 맞게 설정 (단기 작업: 1h, 서비스: 24h~)
- 토큰 발급 이력은 Vault audit log로 관리


## 인증서 네이밍 규칙

**형식**: `[서비스명].[도메인]`
- DNS 레코드(`group_vars/dns_servers.yml`)에 등록된 이름과 일치시킴
- IP로 접근하는 경우 `ip_sans`에 추가

| 서비스 | common_name | ip_sans |
|--------|-------------|---------|
| Proxmox | `proxmox.mgmt.local` | 192.168.34.4 |
| Vault | `vault.sec.local` | 172.16.30.20 |
| MinIO | `minio.mgmt.local` | 172.16.30.70 |
| Harbor | `harbor.mgmt.local` | 172.16.30.200 |
| Nexus | `nexus.mgmt.local` | 172.16.30.15 |
| GitLab | `gitlab.mgmt.local` | 172.16.30.203 |

**발급 방법**
- CLI: `vault write pki_int/issue/internal-services common_name="[서비스].[도메인]" ip_sans="[IP]" ttl=8760h`
- UI: `http://172.16.30.20:8200/ui` → Secrets → pki_int → Generate certificate
